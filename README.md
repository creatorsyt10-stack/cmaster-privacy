CMaster Privacy Policy
Effective date: August 2, 2026

CMaster is a C programming learning app. The app does not require login or signup.

Data Stored On Device
CMaster stores learning progress locally on the device, including completed chapters, quiz scores, saved code snippets, recent compiler runs, theme preference, and daily streak. This data is not used for account identification.

Compiler Use
When users run C code, the code and terminal input may be sent to an online compiler service so the program can be executed and output can be returned. Users should not enter passwords, private keys, or sensitive personal data into the compiler.

Ads
CMaster uses Start.io advertising SDK. The ad provider may collect device, advertising, approximate location, usage, and diagnostics data according to its own policies and user consent/settings.

Children
CMaster is intended for general programming learners and is not directed specifically at children under 13.

Contact
For privacy questions, contact the app publisher through the email listed on the Google Play Store listing.
